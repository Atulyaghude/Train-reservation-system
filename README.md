# Train Reservation System

A responsive Train Reservation System built using HTML, CSS and JavaScript.

**🚀 Live Website:** [Click here to open the website](file:///C:/Users/Atulya%20ghude/Downloads/train_reservation_frontend/train_reservation_frontend/index.html)

## Features
- Book train tickets
- View confirmed and waiting-list passengers
- Search tickets using PNR
- Cancel tickets and promote waiting-list passengers automatically
